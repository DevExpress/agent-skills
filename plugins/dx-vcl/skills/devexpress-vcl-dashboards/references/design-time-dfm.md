# Design time: VCL Dashboards in the `.dfm`

"Design time" means the components and the layout live in the form's `.dfm`, as if placed in the IDE. Write the
`.dfm` blocks below, the matching fields in the form class, and the `uses`/`#include` lines. Format rules:
[dfm-format-rules.md](dfm-format-rules.md). Every block below loads and exports on v26.1+.

## `TDataSet` data (`TdxMemData`, FireDAC) + dashboard control

```
  object pnlDashboard: TPanel
    ...
    object dxDashboardControl1: TdxDashboardControl
      Left = 0
      Top = 0
      Width = 900
      Height = 400
      Align = alClient
      TabOrder = 0
      DashboardName = 'Orders'
      Layout.Strings = (
        ...generated by scripts/Set-DfmLayout.ps1...)
    end
  end
  object dxBackendDataConnectionManager1: TdxBackendDataConnectionManager
    Left = 200
    Top = 40
    object OrdersConnection: TdxBackendDataSetJSONConnection
      DisplayName = 'OrdersConnection'
      object OrdersConnectionItem: TdxBackendDataSetCollectionItem
        DataSource = dsOrders
        DataSetAlias = 'Orders'
      end
    end
  end
```

- **Fields:** `dxBackendDataConnectionManager1: TdxBackendDataConnectionManager; OrdersConnection:
  TdxBackendDataSetJSONConnection; OrdersConnectionItem: TdxBackendDataSetCollectionItem;
  dxDashboardControl1: TdxDashboardControl;`
- **Units:** `dxBackend, dxBackend.ConnectionString.JSON, dxBackend.ConnectionString.JSON.DataSet,
  dxDashboard.Control, cxClasses`.
- **Layout:** `<JsonDataSource ConnectionName="OrdersConnection" RootElement="Orders" .../>`.
- The dataset must be open when the dashboard loads: open it in `FormCreate` or set `Active = True` on a dataset
  that has its data at design time.
- Export from code with `ExportTo*` directly ([export.md](export.md)).

## SQL database (SQLite; other XPO databases use the same component)

```
  object dxBackendDataConnectionManager1: TdxBackendDataConnectionManager
    Left = 40
    Top = 40
    object ShopConnection: TdxBackendDatabaseSQLConnection
      DisplayName = 'ShopConnection'
      ConnectionString = 'XpoProvider=SQLite;Data Source=shop.db'
    end
  end
```
- **Units:** `dxBackend, dxBackend.ConnectionString.SQL, dxDashboard.Control, cxClasses`.
- **Layout:** `<SqlDataSource ...><Connection Name="ShopConnection" FromAppConfig="true" />...`.
- A relative `Data Source` resolves against the exe folder; deploy the database there (post-build:
  `copy /Y "shop.db" ".\bin"` when the exe goes to `bin`).

## Control properties

| `.dfm` line | Meaning |
|---|---|
| `DashboardName = 'Orders'` | Required |
| `ExportFormats = [PDF]` | Viewer Export menu: `PDF`, `Excel`, `Image` (default: all) |
| `OnLayoutChanged = dxDashboardControl1LayoutChanged` | Designer save handler (`procedure(ASender: TdxCustomDashboardControl)`) |
| `OnStateChanged = dxDashboardControl1StateChanged` | Viewer state handler (same signature) |
| `Layout.Strings = (...)` | The Dashboard XML, written by `Set-DfmLayout.ps1` |
| `State.Strings = (...)` | Initial state JSON, e.g. a preselected master filter; one quoted line per JSON line (usually loaded from a file at run time instead) |

## Embedding the layout

Write the Dashboard XML to a file, then:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File <this skill>/scripts/Set-DfmLayout.ps1 -Dfm uMain.dfm -Component dxDashboardControl1 -Layout Orders.xml
```

The script replaces an existing `Layout.Strings` block or adds one; it writes the strings exactly as the IDE does
(quotes doubled, non-ASCII as `#NNNN`, 64-character chunks). Never hand-edit `Layout.Strings`.

## Connections in code instead

When the form already creates its data in code, create the connection in code too (owner = the form) before the
dashboard needs data, e.g. in `FormCreate`: see [data-binding.md](data-binding.md). The control in the `.dfm` finds
it by `DisplayName` when it loads the dashboard.

## C++Builder

The `.dfm` is identical. The header declares the same fields under `__published:`; the `.cpp` includes the units'
`.hpp` files, `#pragma link "dxBackend"` and `#pragma link "dxDashboard.Control"`; the project links
`dxDashboardsRS<nn>.lib` (see SKILL.md). Event handlers:
`void __fastcall dxDashboardControl1LayoutChanged(TdxCustomDashboardControl *ASender);`.
