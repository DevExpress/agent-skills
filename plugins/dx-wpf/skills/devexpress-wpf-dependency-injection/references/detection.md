# Detection

Precondition: read by `inspect`, or by the main agent when it inspects the project itself (see `SKILL.md` → Step 1). Output is facts for `wiring.md` and the plan, not decisions.

## Project facts

| Fact | Where | Why it matters |
|---|---|---|
| DevExpress version | `PackageReference Include="DevExpress.*"` in `.csproj` / `Directory.Packages.props`; or `<Reference Include="DevExpress.*.v26.1">` | 26.1+ has built-in `IocServiceProvider` / `{dxmvvm:Ioc}` |
| DevExpress package kind | `DevExpress.Wpf.*` vs only `DevExpress.Mvvm` (free, open-source build) | The free `DevExpress.Mvvm` package has no `IocServiceProvider` and its locators do not use a container — treat as "no built-in support" |
| Target framework | `TargetFramework(s)` | Microsoft.Extensions package major version; .NET Framework needs the NuGet packages too |
| Existing container | `ServiceCollection`, `IServiceCollection`, `Host.CreateDefaultBuilder`, `Host.CreateApplicationBuilder`, `BuildServiceProvider`, `IServiceProvider` fields/properties on `App` | Must be extended, not duplicated |
| Startup | `StartupUri` in `App.xaml`; `OnStartup`, `App()` constructor, `Main` | Where the composition root goes and what loads before it |
| App-level resources | `App.xaml` resources that declare view models or use `{dxmvvm:Ioc}` | They load before `OnStartup` |

## Creation sites — search and classify

| Kind | Search for | Example of a hit |
|---|---|---|
| `code-behind-new` | `DataContext\s*=\s*new`, `new \w+ViewModel\(` in `*.xaml.cs` / views | `DataContext = new MainViewModel(new Repo())` |
| `xaml-element` | `<\w+:\w+ViewModel\b` inside `.DataContext` property elements, or view models in `Resources` | `<Window.DataContext><vm:MainViewModel/></Window.DataContext>` |
| `poco-runtime` | `ViewModelSource.Create`, `ViewModelSource.Factory`, `dxmvvm:ViewModelSource`, `ViewModelSource Type=` | `DataContext="{dxmvvm:ViewModelSource Type=vm:MainViewModel}"` |
| `scaffolded` | a `protected` constructor plus `public static X Create(` returning `ViewModelSource.Create(() => new X(...))`; often a `?? UnitOfWorkSource.GetUnitOfWorkFactory()` fallback | `OrderViewModel.Create(unitOfWorkFactory)` |
| `base-ctor-override` | a view model that passes a constructor parameter to `base(...)` and overrides a method its base constructor calls (`DocumentsViewModel` → `CreateModules()`) | `MainViewModel : DocumentsViewModel<...>` |
| `compile-time` | `[GenerateViewModel]` | partial class generated by DevExpress.Mvvm.CodeGenerators |
| `view-created-by-service` | `IDialogService`, `IWindowService`, `IDocumentManagerService`, `INavigationService`, `ShowDialog(`, `CreateDocument(`, `Navigate(` with a view name; `ViewTemplate`, `DocumentTemplate` | `ShowDialog(..., "CustomerEditView", null)` |
| `child-view` | UserControls placed in another view's XAML that set their own `DataContext` | `<views:CustomerListView/>` whose XAML declares a view model |
| `service-new` | `new \w+(Service|Repository|Client|Store|Provider|Context)\(` outside tests | `new CustomerRepository()` in a view model constructor |
| `static-singleton` | `\.Instance\b`, `static readonly \w+ Instance`, `static .* Current` | `AuditLog.Instance` |
| `service-locator` | static `Resolve<`/`Get<` helpers, `App.Services`, `((App)Application.Current).`, `GetRequiredService` outside the composition root | `AppServices.Resolve<IRepo>()` |
| `shared-state` | static objects or events used by more than one view model | `SelectionState.Current` read by two view models |

For each creation site also record its dependencies: what it creates with `new`, which singletons or locators it reads.

## DevExpress services

For each `dx:*Service` declared in XAML (`Interaction.Behaviors` or `mvvm:Interaction.Behaviors`): the service type, the element it is attached to, the view model that uses it (`GetService<I...>()`, `ServiceContainer`), and the view names it creates.
